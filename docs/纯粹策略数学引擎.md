## 一、设计哲学

> "每一个持仓决策都必须能被一个数学命题所描述。"

纯粹策略数学引擎的核心信念：策略的**可重复性**和**可解释性**来自严格的数学结构。我们不接受"我感觉这里会涨"，我们接受"当因子 F 满足条件 C 时，期望收益 E[r|C] > 交易成本"。

**三层结构**：
```
因子层 (Factor Layer)      ← 从价格/量/另类数据构造信息
    ↓
信号层 (Signal Layer)      ← 将因子转化为持仓倾向
    ↓
组合层 (Portfolio Layer)   ← 在约束下最优化资本分配
```

## 二、因子层 (Factor Layer)

### 2.1 因子定义语言 (Factor DSL)

因子用声明式 DSL 定义，确保：
- 无前视偏差（look-ahead bias）
- 因子依赖关系可解析（构成 DAG）
- 在回测和实盘中执行完全相同的计算路径

```python
# 示例：动量因子
@factor(lookback=20, universe="liquid_top500")
def momentum_20d(close: Series) -> Series:
    return close.pct_change(20).rank(pct=True) - 0.5

# 示例：成交量加权价差因子
@factor(lookback=5, inputs=["close", "volume"])
def vwap_deviation(close: Series, volume: Series) -> Series:
    vwap = (close * volume).rolling(5).sum() / volume.rolling(5).sum()
    return (close - vwap) / vwap
```

DSL 约束：
- 函数必须是**纯函数**（相同输入 → 相同输出）
- 禁止全局状态访问
- 索引只能向后查历史数据，编译器静态检查

### 2.2 因子分类体系

| 类别 | 典型因子 | 数学基础 |
|------|---------|---------|
| **动量类** | TSM、CSM、残差动量 | 时序/截面收益的自相关 |
| **均值回归类** | Z-score 偏离、RSI 极值 | Ornstein-Uhlenbeck 过程 |
| **波动率类** | 实现波动率、特质波动率 | 方差的估计量 |
| **流动性类** | Amihud 非流动性、买卖价差 | 市场微结构理论 |
| **基本面类** | 盈利修正、资产周转 | 折现现金流 + 增长预期 |
| **另类数据类** | 情绪评分、卫星图像 | 自然语言处理 / 计算机视觉 |

### 2.3 因子正交化

原始因子往往高度相关，需正交化：

```
Gram-Schmidt 正交化：

F̃_k = F_k - Σ_{j<k} proj(F_k, F̃_j)

其中 proj(u, v) = (u·v / v·v) × v
```

实践中使用 PCA 残差化：将因子对已知风险因子（市场、规模、价值）做回归取残差，得到"纯粹的"因子暴露。

### 2.4 因子衰减分析

因子必须有可测量的**信息系数 (IC) 时间序列**：

```
IC_t = rank_correlation(F_{t-lag}, r_t)

IC 均值 (ICIR = IC.mean() / IC.std()) > 0.3 才考虑入库
IC 半衰期 (IC 自相关降至 0.5 的时间) 决定持仓频率
```

## 三、信号层 (Signal Layer)

### 3.1 信号生成器

信号是因子到 **[-1, +1] 区间持仓倾向** 的映射：

```
signal_t = g(F_1t, F_2t, ..., F_kt)

signal > 0  → 做多倾向
signal < 0  → 做空倾向
|signal|    → 置信度
```

### 3.2 信号类型

#### 线性加权信号
```
signal_t = Σ_i w_i × normalize(F_it)

其中 w_i 由 IC 加权或等权确定
normalize: rank → [-0.5, 0.5]（截面标准化）
```

#### 阈值信号（均值回归策略）
```
signal_t = {
    +1  if F_t < μ - k×σ    (超卖，做多)
    -1  if F_t > μ + k×σ    (超买，做空)
     0  otherwise
}
```

k 值通过历史分位数校准，非固定经验值。

#### 机制切换信号
```
regime_t = HMM.predict(features_t)  # 牛市/熊市/震荡

signal_t = signal_bull_t  if regime_t == BULL
         | signal_bear_t  if regime_t == BEAR
         | signal_range_t if regime_t == RANGE
```

### 3.3 信号组合

多个子策略信号的组合：

```
S_combined = Σ_i α_i × S_i

约束：Σ α_i = 1, α_i ≥ 0

α_i 由各子策略的夏普比率、最大回撤、相关性矩阵共同决定
```

## 四、组合层 (Portfolio Layer)

### 4.1 均值方差优化 (MVO)

**经典 Markowitz（带约束）**：

```
min   w' Σ w
s.t.  w' μ ≥ r_target
      Σ w_i = 1
      w_i ∈ [w_min, w_max]
      |w_i - w_benchmark_i| ≤ Δ_i  (跟踪误差约束)
```

Σ（协方差矩阵）估计：
- 历史协方差（样本外效果差）
- Ledoit-Wolf 收缩估计（默认）
- 因子模型协方差：Σ = B F B' + D（降维，稳定性好）

### 4.2 CVaR 优化（尾部风险控制）

```
min   CVaR_α(w)
s.t.  E[r_p] ≥ r_target
      CVaR_α = E[loss | loss > VaR_α]

α = 0.95 (关注最差5%情形的平均损失)
```

用线性规划等价形式求解（Rockafellar-Uryasev 公式）：
```
CVaR_α(w) = min_{z} { z + 1/((1-α)T) × Σ_t max(-r_pt - z, 0) }
```

### 4.3 风险平价 (Risk Parity)

每个资产对组合总风险的**贡献相等**：

```
RC_i = w_i × (Σw)_i / √(w'Σw)

风险平价要求: RC_i = 1/N, ∀i

等价于求解: w_i(Σw)_i = w_j(Σw)_j, ∀i,j
```

适用于对资产收益预测信心不足时（纯风险分散）。

### 4.4 最大分散化 (Maximum Diversification)

```
max  DR = (Σ w_i σ_i) / σ_p

其中 σ_i 为资产 i 的个股波动率
     σ_p = √(w'Σw) 为组合波动率

DR = 1 表示零相关（最大多样化）
```

### 4.5 Kelly 准则（杠杆上限）

当策略有明确胜率/赔率时，用 Kelly 确定最大杠杆：

```
f* = (p × b - q) / b

其中 p = 胜率, q = 1-p, b = 盈亏比

实践中使用半 Kelly（f*/2）作为上限，而非精确 Kelly
```

## 五、统计检验套件

### 5.1 样本内/外分裂测试

```
时间序列分割（非随机！）：

|←─────── 样本内 (IS) ─────────→|←── 样本外 (OOS) ──→|
 70%                               30%

IS Sharpe 与 OOS Sharpe 的比值 > 0.7 才认为过拟合可控
```

### 5.2 Walk-Forward 分析

```
滚动窗口验证：

[IS_1|OOS_1] → Sharpe_1
  [IS_2|OOS_2] → Sharpe_2
    [IS_3|OOS_3] → Sharpe_3

平均 OOS Sharpe 的置信区间（Bootstrap）不包含 0
```

### 5.3 Monte Carlo 压力测试

对历史收益序列进行重采样，验证策略稳定性：

```python
def monte_carlo_sharpe(returns, n_simulations=10000, block_size=20):
    """
    Block Bootstrap 保留时序相关性
    block_size=20 对应月度块，保留自相关结构
    """
    simulated_sharpes = []
    for _ in range(n_simulations):
        sampled = block_bootstrap(returns, block_size)
        simulated_sharpes.append(sharpe_ratio(sampled))
    
    return np.percentile(simulated_sharpes, [5, 25, 50, 75, 95])
```

### 5.4 多重检验校正 (Multiple Testing Correction)

当从大量因子/参数组合中筛选策略时，必须校正 p-value：

```
方法1: Bonferroni 校正（保守）
  α_adjusted = α / N_tests

方法2: BH 校正（FDR 控制，推荐）
  排序 p 值：p_(1) ≤ p_(2) ≤ ... ≤ p_(N)
  接受 p_(k) ≤ (k/N) × α

方法3: Harvey-Liu-Zhu (HLZ) 校正（量化领域专用）
  考虑发表偏误，t-statistic 阈值从 2.0 提升至 3.0
```

## 六、风险归因框架

### 6.1 Brinson-Hood-Beebower (BHB) 分解

```
超额收益 = 配置效应 + 选股效应 + 交互效应

配置效应 = Σ_i (w_i - W_i) × R_i_benchmark
选股效应 = Σ_i W_i × (r_i - R_i_benchmark)
交互效应 = Σ_i (w_i - W_i) × (r_i - R_i_benchmark)
```

### 6.2 因子风险归因

```
组合收益 = α + Σ_k β_k × F_k + ε

β_k = 对因子 k 的暴露（通过时序回归估计）
α   = 纯 alpha（不可被因子解释的超额收益）

目标：最大化 α，而非 β_k（我们不为已知因子暴露付费）
```

### 6.3 实时 P&L 归因

```
ΔPnL = Σ_i Δw_i × r_i + Σ_i w_i × Δr_i

第一项：持仓变化带来的 PnL（交易贡献）
第二项：价格变化带来的 PnL（市场贡献）
```

## 七、数学引擎 API 接口

### 因子注册
```python
engine.register_factor(
    name="momentum_20d",
    func=momentum_20d,
    lookback=20,
    universe_filter="adv > 1e6",  # 日均成交额过滤
)
```

### 信号生成
```python
signal = engine.generate_signal(
    factors=["momentum_20d", "vwap_deviation"],
    weights="ic_weighted",           # 按IC加权
    normalize="cross_sectional_rank" # 截面排名归一化
)
```

### 组合优化
```python
weights = engine.optimize_portfolio(
    signal=signal,
    method="cvar",                   # CVaR 优化
    alpha=0.95,
    constraints={
        "max_position": 0.05,        # 单资产最大5%
        "max_sector_exposure": 0.30, # 单行业最大30%
        "turnover_budget": 0.20,     # 换手率预算
    }
)
```

### 回测快速验证
```python
result = engine.quick_backtest(
    weights_fn=lambda date: weights,
    start="2020-01-01",
    end="2024-12-31",
    slippage_model="vwap_impact",
)
print(result.summary())
# Sharpe: 1.82 | MaxDD: -12.3% | Calmar: 2.1 | Turnover: 18%/月
```
