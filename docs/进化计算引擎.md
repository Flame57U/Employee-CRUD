# 进化计算引擎 (Evolutionary Computation Engine)

> 版本：v0.1 | 日期：2026-05-26 | 视角：经验交易员 × 计算智能

---

## 一、设计哲学

> "参数空间是高维荒原，人工调参是在黑暗中摸索，进化是带着记忆的系统性搜索。"

进化计算引擎（Evo Engine）解决的核心问题：**在巨大参数空间中找到稳健的策略配置，同时避免过拟合**。

关键区别于传统网格搜索：
- **自适应探索**：聪明地跳过无望区域，深挖有潜力区域
- **种群多样性**：同时维护多个解，天然抵抗局部最优
- **过拟合内建防御**：适应度函数直接惩罚 IS/OOS 分裂

**引擎不替代交易员判断**，它负责：
1. 在交易员定义的参数空间内搜索
2. 返回帕累托前沿上的若干候选配置
3. 量化每个候选的鲁棒性证据

最终策略选择权在人，不在算法。

## 二、支持的进化算法

### 2.1 遗传算法 (Genetic Algorithm, GA)

**基本流程**：

```
初始化种群 P_0 (N 个个体, 随机采样参数空间)
    ↓
评估适应度 f(x_i) = backtest(x_i)
    ↓
选择 (Tournament / Roulette / Rank)
    ↓
交叉 (Single-point / Uniform / SBX)
    ↓
变异 (Gaussian / Polynomial)
    ↓
评估后代 → 替换 → 下一代
    ↓
终止条件: 代数 / 适应度收敛 / 时间预算
```

**染色体编码**（策略参数向量）：

```
x = [lookback_period, entry_threshold, exit_threshold,
     stop_loss_pct, take_profit_pct, position_size_pct,
     rebalance_freq, ...]

实数编码（连续参数）
整数编码（离散参数，如 lookback）
二进制编码（开关类参数，如是否启用某因子）
```

### 2.2 差分进化 (Differential Evolution, DE)

对连续参数空间效果优于 GA，收敛更稳定：

```
变异：v_i = x_r1 + F × (x_r2 - x_r3)
      F ∈ [0.4, 0.9]（缩放因子，控制步长）

交叉：u_ij = v_ij  if rand() < CR or j == j_rand
             x_ij  otherwise
      CR ∈ [0.6, 1.0]（交叉率）

选择：x_i^{t+1} = u_i  if f(u_i) ≥ f(x_i)
                  x_i  otherwise
```

DE/rand/1/bin 变体为默认配置，高维参数时切换 DE/current-to-best/1。

### 2.3 粒子群优化 (Particle Swarm Optimization, PSO)

```
v_i^{t+1} = ω × v_i^t
           + c1 × r1 × (pbest_i - x_i^t)   ← 个体最优引力
           + c2 × r2 × (gbest - x_i^t)      ← 全局最优引力

x_i^{t+1} = x_i^t + v_i^{t+1}

参数：
  ω = 0.729  (惯性权重，线性衰减 0.9→0.4)
  c1 = c2 = 1.494  (学习因子)
```

PSO 对平滑目标函数收敛快，但多峰场景容易早熟收敛，配合速度限制和随机重启使用。

### 2.4 协方差矩阵自适应进化策略 (CMA-ES)

高维连续空间的首选算法（参数 > 20 维）：

```
x_k ~ N(m, σ² C)    ← 从多元高斯采样

更新均值：m^{t+1} = Σ_i w_i × x_{i:λ}   (加权最优个体)
更新协方差：C 自适应学习参数间相关性
更新步长：σ 通过累积路径长度自适应

优势：不需要指定交叉率/变异率，自动适应局部曲率
```

## 三、多目标优化框架

### 3.1 为什么需要多目标

单一适应度（如 Sharpe）的问题：
- 最大化 Sharpe 可能意味着极高换手率（忽视交易成本）
- 忽视最大回撤（高 Sharpe + 高 DD 的策略不实用）
- 忽视样本外稳定性（完美 IS，糟糕 OOS）

**目标函数向量**（同时优化，互相权衡）：

```
f(x) = [
    f1: OOS Sharpe 比率              ↑ 最大化
    f2: -1 × 最大回撤               ↑ 最大化（即最小化 DD）
    f3: Calmar 比率 (年化收益/MaxDD) ↑ 最大化
    f4: -1 × 换手率                  ↑ 最大化（即最小化换手）
    f5: IS/OOS Sharpe 分裂比         ↑ 最大化（接近 1.0 为好）
]
```

### 3.2 NSGA-II 算法

```
步骤1：快速非支配排序
  解 a 支配解 b 当且仅当：
    - a 在所有目标上不劣于 b
    - a 在至少一个目标上严格优于 b

  第一前沿 F1：不被任何解支配的解集
  第二前沿 F2：仅被 F1 支配的解集
  ...

步骤2：拥挤度距离
  同一前沿内，优先保留参数空间中"稀疏"的解
  → 维持解的多样性，防止帕累托前沿某段收敛

步骤3：选择
  先按前沿等级排，同级按拥挤度降序排
```

### 3.3 帕累托前沿可视化

最终输出帕累托前沿，交易员从中选择符合自己风险偏好的点：

```
OOS Sharpe
    ↑
2.5 │                              ★ (低DD,高Sharpe,但换手高)
    │                         ★
2.0 │                    ★
    │              ★
1.5 │         ★
    │    ★
1.0 │★
    └─────────────────────────────→ 最大回撤
       5%    10%    15%    20%

★ = 帕累托最优解，每个点均不被其他点完全支配
```

## 四、过拟合防御机制

这是进化引擎最核心的工程挑战：进化算法天然倾向于对训练数据过拟合。

### 4.1 适应度函数内建惩罚

```python
def fitness(x, is_returns, oos_returns):
    is_sharpe  = sharpe_ratio(backtest(x, is_returns))
    oos_sharpe = sharpe_ratio(backtest(x, oos_returns))
    
    # 过拟合惩罚：IS/OOS 分裂越大，惩罚越重
    overfit_penalty = max(0, (is_sharpe - oos_sharpe) / is_sharpe)
    
    # 参数复杂度惩罚（避免过多自由度）
    complexity_penalty = 0.1 * count_free_params(x)
    
    return oos_sharpe - 0.5 * overfit_penalty - complexity_penalty
```

### 4.2 Walk-Forward 适应度

不用固定 IS/OOS 分割，用滚动窗口的平均 OOS 表现作适应度：

```
WF_fitness(x) = mean([
    oos_sharpe(window_1, x),
    oos_sharpe(window_2, x),
    oos_sharpe(window_3, x),
    oos_sharpe(window_4, x),
])

方差 std(oos_sharpes) 过大的解直接淘汰（策略时间稳定性差）
```

计算成本约为单次回测的 4 倍，但过拟合防御效果显著提升。

### 4.3 噪声注入测试

```python
def robustness_score(x, returns, n_noise_trials=50):
    """
    对参数加入小扰动，测试策略稳定性
    好策略：参数微调不导致性能崩溃
    """
    base_sharpe = backtest_sharpe(x, returns)
    noise_sharpes = []
    
    for _ in range(n_noise_trials):
        x_noisy = x + np.random.normal(0, 0.02 * abs(x), size=x.shape)
        noise_sharpes.append(backtest_sharpe(x_noisy, returns))
    
    # 稳健性 = 噪声后性能保留率
    return np.mean(noise_sharpes) / base_sharpe
```

只有 `robustness_score > 0.8` 的候选才进入帕累托前沿。

### 4.4 种群多样性维护

```
多样性度量：
  D(P) = (1/N²) × Σ_{i,j} ||x_i - x_j||₂

当 D(P) < D_min 时（种群收敛过快）：
  1. 随机重启 20% 个体（覆盖参数空间其他区域）
  2. 增大变异步长 σ × 1.5
  3. 岛屿模型迁移（见第五节）
```

## 五、并行架构：岛屿模型

### 5.1 设计原理

单一大种群容易早熟收敛。**岛屿模型**（Island Model）将种群分割为多个隔离的子种群，定期交换精英：

```
岛屿 A (GA)        岛屿 B (DE)        岛屿 C (PSO)
[种群 A]    ←迁移→  [种群 B]    ←迁移→  [种群 C]
    ↓                    ↓                   ↓
回测集群 (Ray)      回测集群 (Ray)      回测集群 (Ray)
```

### 5.2 迁移策略

```
迁移频率：每 10 代迁移一次
迁移规模：每个岛屿输出 top 5% 个体
迁移拓扑：环形（A→B→C→A）或全连接

接收策略：
  - 替换最差个体（精英移植，快速传播好基因）
  - 替换随机个体（保持多样性，推荐）
```

### 5.3 Ray 分布式调度

```python
@ray.remote
class Island:
    def __init__(self, algo, params):
        self.algo = algo
        self.population = initialize_population(params)
    
    def evolve_one_generation(self):
        # 并行评估种群中所有个体（每个个体一次回测）
        futures = [backtest.remote(x) for x in self.population]
        fitnesses = ray.get(futures)
        self.population = self.algo.select_and_evolve(
            self.population, fitnesses
        )
        return self.get_top_individuals(pct=0.05)
    
    def receive_migrants(self, migrants):
        worst_idx = np.argsort(self.fitnesses)[:len(migrants)]
        for i, idx in enumerate(worst_idx):
            self.population[idx] = migrants[i]

# 编排
islands = [Island.remote(algo, params) for algo in [GA, DE, PSO]]
for generation in range(MAX_GENERATIONS):
    # 所有岛屿并行进化
    elites = ray.get([island.evolve_one_generation.remote()
                      for island in islands])
    # 环形迁移
    for i, island in enumerate(islands):
        island.receive_migrants.remote(elites[(i-1) % len(islands)])
```

**吞吐量**：100 个 worker 节点，每代并行 1000 次回测，单代耗时 < 60 秒。

## 六、适应度函数设计指南

### 6.1 基础适应度函数库

| 函数名 | 公式 | 适用场景 |
|--------|------|---------|
| `sharpe` | μ_r / σ_r × √252 | 通用，首选 |
| `calmar` | 年化收益 / MaxDD | 重视回撤控制 |
| `sortino` | μ_r / σ_downside × √252 | 不对称风险 |
| `omega` | E[max(r-L,0)] / E[max(L-r,0)] | 完整分布敏感 |
| `profit_factor` | 总盈利 / 总亏损 | 高频策略 |

### 6.2 复合适应度（推荐）

```python
def composite_fitness(metrics):
    """
    加权复合，权重由交易员根据策略目标设定
    """
    return (
        0.35 * normalize(metrics.oos_sharpe)
      + 0.25 * normalize(-metrics.max_drawdown)
      + 0.20 * normalize(metrics.calmar)
      + 0.10 * normalize(-metrics.turnover)
      + 0.10 * normalize(metrics.oos_ois_ratio)  # IS/OOS稳定性
    )
```

### 6.3 禁止事项

- **禁止**以 IS Sharpe 为主要适应度（直接导致过拟合）
- **禁止**忽略交易成本（美化的曲线没有实盘价值）
- **禁止**使用未来数据的任何统计量（如用全样本均值归一化）
- **禁止**将参数设置为没有经济意义的极端值（如 lookback=1 天）

## 七、终止条件与收敛判断

```python
class ConvergenceMonitor:
    def should_stop(self, generation, population, fitnesses):
        # 条件1：超过代数上限
        if generation > self.max_generations:
            return True, "代数上限"
        
        # 条件2：超过时间预算
        if elapsed_time() > self.time_budget:
            return True, "时间预算"
        
        # 条件3：种群适应度收敛（最优不再改善）
        recent_best = [max(hist_fitnesses[-g]) 
                       for g in self.history[-20:]]
        if np.std(recent_best) < 0.001:
            return True, "适应度收敛"
        
        # 条件4：种群多样性耗尽
        diversity = population_diversity(population)
        if diversity < self.min_diversity:
            return True, "多样性耗尽"
        
        return False, None
```
